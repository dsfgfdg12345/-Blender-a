零基础也能做出自己的三渲二角色？30天原创修炼路线图
三渲二最劝退新手的不是技术难度，而是“什么都得会一点”：建模、拓扑、UV、着色器、灯光、渲染，每一项单独看都有大量教程，合在一起就不知道从哪下手。30天路线图的核心思路是：不追求一次学完所有功能，而是按“先出形、再出色、后出图”的顺序，每周只攻一个目标，最后拼出一个完整的原创角色。零基础可以走，有基础的人可以压缩周期，但阶段顺序不能乱。

第一周：定方向、练观察、出剪影。 这周不碰复杂建模，只做三件事。第一，定角色方向：写一句话描述你的角色——什么气质、什么体型、什么职业感、一个记忆点。方向越具体，后面越不容易跑偏。第二，练观察：找五到十张三渲二参考图，不看细节，只看剪影和比例，分析它们头身比多少、重心在哪、哪个部位被夸张、哪个部位被概括。第三，出剪影：用最简单的几何体拼角色大形，只关心正面和侧面剪影能不能读出角色气质。每天拼一个版本，改到缩小看还能认出是谁。周末做一次自检：剪影有没有主次、比例有没有节奏、记忆点够不够突出。剪影不过关，绝不进入下一周。

第二周：建粗模、定体块、练拓扑意识。 这周目标是做出一个“能看但还不美”的完整粗模。先从大体块开始：头、躯干、四肢用基本形搭建，确保比例和剪影与第一周定稿一致。然后做中观结构：关节转折、衣物大形、发型大块，全部用低面数概括，不要碰小细节。拓扑意识从现在就要有：布线跟着形体走，关节处留环线，面数控制在能改动的程度。这周的关键心态是“允许丑”：粗模不需要好看，只需要结构对、比例对、能继续往下做。周末做一次检查：从三四个角度看体块有没有穿插、关节能不能弯、衣物有没有厚度感。粗模阶段偷懒，后面着色和渲染全是坑。

第三周：学三渲二着色逻辑、打灯光、出第一张色稿。 这周开始接触三渲二的核心：不是把材质调平，而是用着色器控制“亮部、暗部、边缘光”三层关系。先做最简版本：一个主色、一个暗部色、一条边缘光，用光照方向驱动明暗分界，确保分界线干净、暗部不是死黑而是有色彩倾向。然后加第二层：材质区分——皮肤、布料、金属各自有不同的高光宽度和暗部色相，但整体保持在同一个色彩体系里。灯光这周只做一件事：用一个主光加一个补光，把角色的体积和轮廓打出来，不要急着加环境光。周末出一张正面色稿，检查三件事：明暗分界是否清楚、暗部颜色是否成立、边缘光有没有把角色从背景里拉出来。色稿不过关，不回建模阶段改，而是在着色阶段调，训练自己用材质语言解决问题。

第四周：加细节、做表情、出成品图。 这周分两段。前半周加“有选择的细节”：只在视觉焦点处加信息——脸部五官、发型走向、衣物主要褶皱、一个标志性配件，其他区域保持概括。细节必须服从剪影和色块，不能破坏第三周建立的三层光影关系。后半周做表情和最终渲染：给角色一个能读出情绪的表情，眼睛和嘴巴做两到三个版本选最优；渲染时统一色调、检查边缘、处理噪点，输出一张正面半身成品图。最后留一天做复盘：记录哪一步最卡、哪个决定后来被推翻了、下次会怎么改。复盘比成品更重要，因为它决定你第二个角色能不能做得更快。

30天路线图的本质是“用完整流程喂出判断力”。零基础最大的误区是每个模块都学一半就换下一个，结果永远拼不出完整作品。按周锁定目标、周末验收、不过关不推进，30天后你手里会有一个不完美但完整的原创三渲二角色，以及一套可以复用的工作顺序。第二个角色开始，你只需要重复这张路线图，把每个阶段的判断标准调得更准。
